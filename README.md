# π

**π is not just 3.141592653589793.**

It is 4,000 years of human effort, an unproven mystery, and the most computed
number on Earth. This repository is a complete home for it: a game you can
play, an atlas you can read, algorithms you can run, and a million digits you
can trust.

**[Play the site](https://amey-thakur.github.io/PI/)** ·
[Read the atlas](atlas/README.md) ·
[Run the algorithms](algorithms/README.md) ·
[Climb the challenges](challenges/README.md)

## The site

**[amey-thakur.github.io/PI](https://amey-thakur.github.io/PI/)** is a
gamified single page with eight interactive labs and eight badges to earn:

| Lab | What happens | Badge |
|---|---|---|
| Digit Trainer | Recite π from memory, three misses and you are out | First Digits, Memory of Pi |
| Digit Search | Find your birthday inside a million decimals | Digit Hunter |
| Monte Carlo | Watch random darts converge on π | Estimator |
| Buffon's Needle | The 1777 experiment, live on a lined floor | Needle Dropper |
| Digit Walk | The decimals steer a walker across the canvas | Wanderer |
| Digit Spiral | Ten thousand digits wound into colored rings | |
| Pi Melody | The digits played on a pentatonic scale | Composer |
| Digit Census | Frequency of 0 to 9, tested with chi-square | |
| History quiz | Five questions across 4,000 years | Historian |

No accounts, no servers, no trackers, no external requests. Every byte is in
this repository, so the whole experience works offline.

## The algorithms

Twenty two working implementations in [`algorithms/`](algorithms/README.md),
from Archimedes' polygons to the Chudnovsky series that holds every modern
record. Python, JavaScript, and Rust, standard library only, one algorithm
per file, every file runnable in seconds:

```
py   algorithms/python/chudnovsky.py
node algorithms/javascript/machin.js
```

## The challenges

Twenty five challenges in [`challenges/`](challenges/README.md), from
memorizing ten digits to computing a million and verifying them yourself.
Four tiers: Novice, Apprentice, Expert, Master. Hints and solutions are
sealed in folding sections, so nothing is spoiled early.

## The data

[`data/`](data/README.md) holds 1,000, 10,000, 100,000, and 1,000,000
verified decimals of π. Verified means exactly this:

1. Generated by the Chudnovsky series with binary splitting
   ([`scripts/generate_digits.py`](scripts/generate_digits.py)).
2. Recomputed from scratch by the unrelated Gauss-Legendre iteration on a
   different arithmetic engine
   ([`scripts/verify_digits.py`](scripts/verify_digits.py)).
3. Published only because both computations agree on every single digit.

That is the same standard world record computations use, applied at
repository scale. Regenerate everything yourself with two commands.

## Questions people ask

- **How many digits does anyone need?** NASA JPL steers interplanetary
  spacecraft with 15 decimals. About 37 digits would size the observable
  universe to within a hydrogen atom. The rest is sport, benchmarking, and
  mathematics. See [Records](atlas/06-records.md).
- **Is my birthday in π?** Almost certainly, and the
  [site](https://amey-thakur.github.io/PI/) will find it. Every 4 digit
  string tends to show up within the first ten thousand decimals or so.
- **Are the digits random?** They pass every statistical test thrown at
  them, yet nobody has proved they must. That gap is one of the great open
  problems: see [What nobody knows](atlas/07-open-problems.md).
- **What is the record?** 314 trillion digits, as of mid 2026. The full
  ladder from clay tablets onward is in [History](atlas/02-history.md).
