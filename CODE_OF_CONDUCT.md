# Code of Conduct

## The standard

This project is a place to build something useful together. Everyone taking
part, in issues, pull requests, and discussions, is expected to keep it that
way.

Treat people with respect. Assume good faith. Give feedback on the work, not
the person. Welcome newcomers and questions; everyone met π for the first
time once.

These are out of bounds: harassment, insults, discrimination, personal
attacks, sharing others' private information, and any conduct that would be
unreasonable in a professional setting.

## Scope

This applies in every project space, on GitHub and elsewhere, and whenever
someone is representing the project in public.

## Reporting

Report unacceptable behavior privately to **ameythakur20@gmail.com**. Every
report is reviewed and handled discreetly. The maintainer may warn, remove
content, or ban a contributor whose behavior does not stop.
