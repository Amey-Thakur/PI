# The Pi Challenge Ladder

Twenty five challenges in four tiers, each one small enough to finish and
real enough to matter. The rules are simple: go in order within a tier,
attempt before opening the hint, and treat the sealed solution as a
conversation with someone who already climbed, not an answer key. Every
number printed in every solution was produced by running the code shown, and
most check themselves against the repository's
[verified digits](../data/README.md).
